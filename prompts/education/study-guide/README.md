# Active Study Guide Generator

## Overview
This prompt transforms raw, unstructured study notes or textbook excerpts into an active learning study guide complete with core concept summaries, vocabulary definitions, and self-testing recall questions.

## Quick Start
1. Copy the template from `prompt.md`.
2. Fill in the `[PLACEHOLDERS]` with your subject, target grade level, and raw notes or topic text.
3. Run the prompt in your AI model to generate a structured revision guide.

## Expected Output
An organized study tool featuring Core Concepts, Key Vocabulary, and 5 Active Recall Self-Test Questions.
